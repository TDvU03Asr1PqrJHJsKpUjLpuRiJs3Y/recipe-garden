> # シーフードパエリア・レシピ（約4食分）

> [!abstract] 参考
> 魚介を先に炒めて旨味を引き出し、その煮汁を米に吸わせて炊き上げる、フライパン1枚で作るシーフードパエリアだよ。工程自体はそこまで複雑ではないけれど、**魚介を取り出すタイミング** と **煮汁を戻す流れ** が味を左右するレシピじゃ。

> ## 概要

| 項目 | 内容 |
| --- | --- |
| 料理の特徴 | 魚介の旨味を米に吸わせて仕上げる、王道寄りのシーフードパエリア |
| 分量 | 約4食分 |
| 主な流れ | 魚介を炒める → 煮汁を取る → 香味野菜と米を炒める → スープで炊く → 具材を戻して仕上げる |

> ## 下準備

| 項目 | やること | 目的 |
| --- | --- | --- |
| えび | 背ワタを取る | 臭みを抑えて食べやすくする |
| あさり | 砂抜き済みか確認する | じゃりつきを防ぐ |
| にんにく | みじん切りにする | 香りを出しやすくする |
| 玉ねぎ | みじん切りにする | 甘みをなじませやすくする |
| トマト | 乱切りにする | 炊き込み時に崩れて旨味を出す |
| パプリカ | 小さめのさいの目切りにする | 仕上げで均一に火を通しやすくする |
| レモン | くし切りにする | 食べる直前に酸味を足せるようにする |
| ストック | チキンストックにサフランを入れておく | 色と香りをなじませ、入れ忘れを防ぐ |

> [!warning] 重要
> 材料にはサフランがあるのに、元の工程文では投入タイミングが抜けていたよ。作るときは **チキンストックにサフランを入れておき、液体と一緒に加える** と覚えておくのが安全じゃ。

> ## 全体の流れ

| 手順 | 内容 |
| --- | --- |
| 1 | 魚介を炒めて、えび・いか・あさりを順に取り出す |
| 2 | あさりを蒸した煮汁を取っておく |
| 3 | にんにくと玉ねぎを炒める |
| 4 | 米を加えて油をなじませる |
| 5 | トマト、ストック、煮汁、調味料を加えて炊き始める |
| 6 | 途中でパプリカと魚介を戻して仕上げる |
| 7 | 蒸らして、レモンとハーブで完成させる |

> ## 手順

| 工程          | やること                                                                                                                                                         | 火加減・時間      | ポイント                   |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------- | ---------------------- |
| 1. 魚介を炒める   | フライパンにオリーブオイルを入れて中火で熱し、魚介を一度に加えて炒める。えびといかに火が通ったら先に取り出しておく。<br><br>**使う材料：**<br>・オリーブオイル（魚介用）（14g）<br>・あさり（150g）<br>・えび（300g）<br>・いか（100g）                    | 中火で数分       | えびといかは火が通ったら先に取り出す     |
| 2. あさりを開かせる | えびといかを取り出したフライパンに白ワインを回しかけ、フタをして中火で蒸す。あさりの口が開いたら取り出し、フライパンに残った煮汁は別の容器に取り出して分けておく。<br><br>**使う材料：**<br>・白ワイン（60ml）                                                  | 中火          | 開いたあさりを取り出し、煮汁は別の容器に分けておく    |
| 3. 香味野菜を炒める | 煮汁が残ったままのフライパンにオリーブオイルを足し、にんにくを加えて中火で熱する。香りが立ったら玉ねぎを加え、透き通るまで炒める。<br><br>**使う材料：**<br>・オリーブオイル（炒め用）（28g）<br>・にんにく（5g）<br>・玉ねぎ（100g）                          | 中火で1〜3分     | 玉ねぎが透き通るまで進める          |
| 4. 米を炒める    | 玉ねぎが透き通ったら、研がずそのままの米を加え、全体をなじませるよう中火で炒める。米の表面全体が油でコーティングされるまで炒める。<br><br>**使う材料：**<br>・米（300g）                                                               | 中火で1〜2分     | 米は研がずに使い、表面を油でコーティングする |
| 5. 液体を加える   | 米に油がなじんだら、トマト・チキンストック・魚介の煮汁・サフラン・塩・ブラックペッパーをすべて加え、全体を大きく混ぜ合わせる。強火にして沸騰させる。<br><br>**使う材料：**<br>・トマト（200g）<br>・チキンストック（400ml）<br>・魚介の煮汁<br>・サフラン（0.5g）<br>・塩（6g）<br>・ブラックペッパー（1g） | 加えたら強火で沸騰まで | サフランもここで加える |
| 6. 炊く       | 沸騰したら混ぜるのをやめ、アルミホイルをフライパン全体に密着させてフタにする。弱火に落とし、開けずにそのまま炊く。                                                                                                    | 弱火で12分      | 米に旨味を吸わせる中心工程          |
| 7. 具材を戻す    | 12分炊いたら、取り出しておいた具材を米の上に広げてのせる。混ぜ込まずに表面に並べるだけ。再びアルミホイルでフタをする。<br><br>**使う材料：**<br>・パプリカ赤（40g）<br>・パプリカ黄（40g）<br>・いか（100g）<br>・あさり（150g）<br>・えび（300g）          | 弱火のまま       | この段階では混ぜ込まず、上に広げてのせる   |
| 8. 仕上げ加熱    | フタをしたまま弱火で加熱し、魚介全体に均一に火を通す。                                                                                                                                  | 弱火で8分       | 魚介を温め直しつつ全体を仕上げる       |
| 9. 蒸らす      | 火を止め、フタをしたままの状態で蒸らす。蒸らし中は開けずに待つ。                                                                                                                             | 5分          | 水分と熱を落ち着かせる            |
| 10. 仕上げる    | 蒸らし終えたらフタを開け、くし切りにしたレモンを全体にのせ、イタリアンハーブミックスを散らす。<br><br>**使う材料：**<br>・レモン（50g）<br>・イタリアンハーブミックス                                                               | 仕上げ         | 食べる直前にレモンを絞ると味が締まる     |

> ## 時間の目安

| 区分 | 時間 |
| --- | --- |
| 弱火で炊く | 12分 |
| 具材をのせて再加熱 | 8分 |
| 蒸らし | 5分 |
| 明記されている加熱時間の合計 | 25分 |
| 下準備・炒め時間込みの全体目安 | 35〜45分 |

> ## ひと目でわかる進行順

| フェーズ | やること |
| --- | --- |
| 前半 | えびの背ワタを取り、野菜を切り、魚介を炒めて煮汁を確保する |
| 中盤 | にんにくと玉ねぎを炒め、米に油をなじませ、トマトとストックで炊き始める |
| 後半 | パプリカと魚介を戻し、8分加熱してから5分蒸らし、レモンとハーブで仕上げる |

> [!danger] 最重要
> このレシピでいちばん大事なのは、**あさりの煮汁を捨てないこと** と **魚介を最初に加熱しすぎないこと** だよ。ここを外すと、旨味も食感もかなり落ちやすいじゃん。

> ## 注意点

| 論点 | 内容 |
| --- | --- |
| 米の扱い | このレシピは研がずに使う前提。研ぐと水分状態が変わって食感がずれやすい |
| 魚介の火入れ | えびといかは途中で一度取り出し、最後に戻すことで固くなりにくい |
| 煮汁の扱い | あさりを蒸した煮汁は、パエリア全体の旨味の核になる |
| サフラン | 入れ忘れやすいので、最初にチキンストックへ入れておくと安全 |
| フライパンのサイズ | 25cmより小さいと中心がややリゾット寄りになりやすい |
| えびの殻 | 殻付きのほうが出汁感は出やすいが、食べやすさとのバランスで選ぶ |
| 代用案 | シーフードミックスでも代用可能。ただし殻付きえびより旨味は弱くなりやすい |
| 保存 | 残りを冷凍するなら、貝の殻は外してからのほうが扱いやすい |

> ## まとめ

| 要点 | 内容 |
| --- | --- |
| レシピの核 | 魚介を先に炒めて煮汁を取り、その旨味を米に吸わせること |
| 時間の軸 | 12分炊く → 8分仕上げ加熱 → 5分蒸らす |
| 失敗しやすい点 | 魚介の加熱しすぎ、煮汁を捨てる、サフランの入れ忘れ |
| 作りやすくするコツ | サフランはストックへ先入れ、具材は途中で取り出して最後に戻す |
